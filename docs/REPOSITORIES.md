## Product source and ownership

Product source remains private in its current repository. This public documentation does not expose customer data or grant access to the client workspace.

The current organisation publishes the public materials. Any transfer of the private application should be planned together with its deployment and integration ownership: hosting, authentication redirects, environment variables, Actions, webhooks, secrets and installed apps need to remain correctly connected. A profile update is not a repository migration.
