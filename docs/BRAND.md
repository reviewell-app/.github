# Reviewell — identity assets

These assets are available for this organisation's GitHub materials.

| Asset | File | Use |
| :--- | :--- | :--- |
| Organisation avatar | [PNG](../assets/avatar.png) | Square profile image |
| Profile banner | [SVG](../assets/banner.svg) | Organisation start page |

Use the original proportions and maintain sufficient contrast. SVG artwork scales without a loss of resolution; the avatar is supplied as a square PNG.

This asset directory does not imply an open-source licence or permission to represent yourself as the product. For external use or partnership enquiries, start at [https://reviewell.com](https://reviewell.com).

## Profile maintenance

Edit `profile/README.md` for the public start page and `assets/` for artwork. Keep link text descriptive, include image alternatives and check the rendered result on GitHub. Product screenshots and data exports should be identified as captures rather than live feeds.
